# Matriz de Necessidades — FAM

| Código | Necessidade | Objetivo |
|---|---|---|
| N01 | Segurança | identificar necessidade de proteção/resposta imediata |
| N02 | Saúde | identificar necessidade de atendimento |
| N03 | Proteção | orientar para mecanismos e serviços |
| N04 | Informação | explicar caminhos e possibilidades |
| N05 | Apoio | oferecer orientação inicial |
| N06 | Orientação especializada | indicar serviço/profissional competente |

As necessidades não devem ser convertidas automaticamente em diagnóstico ou classificação criminal.
